rclone-drive

rclone-drive는 개인 측정 장비(라즈베리파이)가 만든 통화 품질 측정 결과를 사용자 본인의 Google Drive에 올리기 위해 쓰는 개인용 OAuth 클라이언트입니다. 업로드에는 오픈소스 도구 rclone을 씁니다.

  • 권한 범위는 drive.file뿐입니다 — 이 앱이 직접 만든 파일과 폴더에만 접근하고, Drive의 다른 파일은 보거나 바꾸지 않습니다.
  • 데이터는 사용자 본인의 Drive에만 저장되며 다른 서버로 보내지 않습니다.

About (English)

rclone-drive is a personal OAuth client used by the owner's own measurement device (a Raspberry Pi) to upload call-quality measurement results to the owner's own Google Drive with the open-source tool rclone. It requests only the drive.file scope, so it can access only files and folders it created itself. Data is stored only in the owner's Drive and is not sent to any other server.
