개인정보처리방침

시행일: 2026-11-19

1. 쓰는 정보

rclone-drive는 Google 계정 인증으로 받은 접근 권한(drive.file 범위)만 씁니다. 이 권한으로 이 앱이 만든 파일·폴더를 만들고, 읽고, 지웁니다. Drive의 다른 파일, 연락처, 메일 등 그 밖의 Google 사용자 데이터에는 접근하지 않습니다.

2. 쓰는 목적

사용자 본인의 측정 장비가 만든 측정 결과(측정 기록·녹음·보고서)를 사용자 본인의 Google Drive에 보관하는 데만 씁니다.

3. 보관과 공유

데이터는 사용자 본인의 Google Drive에만 저장됩니다. 개발자 서버를 포함한 어떤 제3자에게도 보내거나, 팔거나, 공유하지 않습니다. 광고나 분석에 쓰지 않습니다. 인증 토큰은 사용자 본인의 장비 안에만 보관됩니다.

4. 삭제와 권한 철회

올린 데이터는 Google Drive에서 언제든 직접 지울 수 있습니다. 접근 권한은 Google 계정 › 서드 파티 연결에서 언제든 철회할 수 있습니다.

5. Google API 서비스 사용자 데이터 정책

rclone-drive가 Google API에서 받은 정보를 쓰고 옮기는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

Privacy Policy

Effective: 2026-11-19

1. Data accessed

rclone-drive uses only the access granted through Google sign-in with the drive.file scope, to create, read and delete files and folders that this app itself created. It does not access any other Drive files, contacts, mail or other Google user data.

2. Purpose

The access is used only to store measurement results (records, audio recordings, reports) produced by the owner's own measurement device in the owner's own Google Drive.

3. Storage and sharing

Data is stored only in the user's own Google Drive. It is not sent, sold or shared to any third party, including the developer's servers, and it is not used for advertising or analytics. Authentication tokens stay on the user's own device.

4. Deletion and revoking access

Uploaded data can be deleted from Google Drive at any time. Access can be revoked at any time at Google Account › Third-party connections.

5. Google API Services User Data Policy

rclone-drive's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
